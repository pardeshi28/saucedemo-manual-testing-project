# SauceDemo Manual Testing Project

## Project Overview

This is a hands-on manual testing project performed on the SauceDemo e-commerce web application.

The project demonstrates the complete manual testing lifecycle from test scenario identification and test case design to test execution, defect reporting, RTM and test summary.

## Application Under Test

SauceDemo E-Commerce Web Application

## Modules Tested

- Login
- Products
- Shopping Cart
- Checkout

## Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Testing
- UI Testing
- Validation Testing
- End-to-End Testing

## QA Documentation

- Test Scenarios
- Test Cases
- Test Execution
- Defect Report
- Requirement Traceability Matrix (RTM)
- Test Summary Report
- Test Evidence
