# 🧪 SauceDemo Manual Testing Project

## 📌 Project Overview

This is a hands-on **Manual Testing project** performed on the SauceDemo e-commerce web application.

The project demonstrates the complete software testing lifecycle, including test scenario identification, test case design, test execution, defect reporting, defect tracking, requirement traceability, and test summary reporting.

## 🐞 Defect Identified

### BUG_CHECKOUT_001

**Module:** Checkout

**Issue:** Postal Code field accepts invalid input.

**Jira Issue:** `SMT-1`

**Status:** Open

The defect was identified during negative and boundary testing of the Postal Code field.

Invalid values such as incorrect-length, alphabetic, alphanumeric, and special-character inputs were accepted by the application when they were expected to be rejected.
